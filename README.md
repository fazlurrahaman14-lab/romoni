# Ledis Dress Luxury E-Commerce

Modern, mobile-first, high-performance luxury e-commerce web application for **Ledis Dress** inspired by Mushq and Ammara Khan.

## Features
- **Mobile-First UX**: Cellphone-optimized sticky bottom navigation bar, touch drawer menu, fast slide-up filter sheet.
- **Dynamic Multi-Currency Converter**: Real-time switching between PKR, USD, GBP, EUR, AED, SAR.
- **WhatsApp Express Order**: Direct order button pre-populating suit SKU, size, and details.
- **Interactive Cart & Checkout**: Free shipping progress bar, promo code validation (`LEDIS10`), confetti celebration, and printable order receipts.

## Getting Started
```bash
npm install
npm run dev
```
